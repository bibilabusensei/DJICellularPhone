## Android 兼容实验版 v0.1.0

在页面底部 **Assets** 点击 **DJICellularAndroid-debug.apk** 即可下载。公开 Release 不使用需要登录的 Actions 附件入口；APK 已使用测试签名，不需要用户另行签名，也不需要解压。

### 版本与兼容目标

- 最低 Android 5（API 21），面向 Android 10/11 和纯 Wi-Fi GSI 平板。
- 无需 root，不依赖平板内置 SIM；需要 USB Host/OTG、适当供电和用户的 USB 设备授权。
- 已通过编译、lint、最低 API 和 APK 签名核验；**尚未在 Android 5/11 或用户 GSI 真机上验收**。
- 这是已经构建好的原候选 APK，直接转存发布，没有重新编译或更换其测试签名。

### 已实现的实验功能

- 限定 `2CA3:4009` / `MI_02` 的 USB AT 握手与状态查询。
- 有前提限制的单条 UCS-2 短信提交、模块存储短信读取、用户开启后的前台监听。
- 逐次确认的来电/呼叫控制实验；存在数据或未知呼叫时拒绝操作，避免影响数据。
- 仅使用系统已有以太网、且模块近期本地注册成立时的 HTTPS 小流量测试，不回退平板 Wi-Fi。

### 不是全功能电话或系统上网驱动

**没有双向通话声音、用户态 QMI 数据驱动或 Android 系统蜂窝网络集成。短信、来电和模块实际数据路径也尚未通过真机验证。** 不能因为按钮存在、编译成功或 AT 命令被接受，就当作可以正常通话上网。

历史模块能力列表没有列出部分短信/挂断命令，实际支持仍需逐项确认；软件不会通过切模式、刷固件、改 IMEI/APN 或抢占网卡来强行启用。

先不接模块安装并确认 App 可以启动。确认 OTG/供电安全后，只尝试“连接模块并查询状态”并分享诊断；**先不要启用无声音、可能收费的呼叫实验，更不要用于紧急/正式呼叫**。读取短信可能将其标为已读，但不会删除记录。断开 USB 不会自动结束已开始的电话。

测试签名不是生产签名；未来不同构建可能需要先卸载旧版再安装。没有改模块固件、USB 模式或电脑网卡，也没有验证装回无人机后的功能。
